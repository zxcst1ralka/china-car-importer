# China Car Importer

WordPress-плагин и дизайн-система «под ключ» для компании, которая привозит автомобили из Китая: каталог с ценой «под ключ», калькулятор пошлин, заявки, платная проверка VIN с оплатой через ЮKassa и полностью свой фронтенд (тема не нужна).

> **Витрина проекта:** https://zxcst1ralka.github.io/china-car-importer/
>
> **Живое демо:** `https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/zxcst1ralka/china-car-importer/main/blueprint.json`
> (откроется временный WordPress в браузере с уже установленным плагином, демо-данными и входом в админку)

## Что умеет

**Сайт для клиентов**
- Главная с видео, которое «листается» скроллом (павильон открывается, этапы: подбор → проверка → таможня → выдача)
- Каталог с чипами-фильтрами и карточками: цена «под ключ» и раскрывающийся разбор «из чего складывается цена»
- Интерактивный калькулятор: пошлина зависит от возраста, объёма, мощности и типа двигателя; результат считает тот же алгоритм, что и каталог
- Страница проверки по VIN: 17-клеточный ввод, переключение режима (оплата сразу / холд по ссылке)
- Страницы каждого автомобиля и марки (SEO), sitemap, микроразметка
- Блоки доверия из админки: отзывы, кейсы, документы, условия сделки, вопросы-ответы
- Квиз-форма подбора из 3 шагов, Яндекс.Метрика с целями, UTM-источники в заявках
- Защита от ботов, SEO-мета, Open Graph, шаблон политики конфиденциальности, уведомление о cookie

**Админка (для менеджера, без технических знаний)**
- Обзор: счётчики, чек-лист готовности сайта, подсказки
- Заявки: статусы, поиск, бюджет отдельным столбцом, выгрузка в Excel
- Автомобили: добавление/редактирование лота, фото из медиатеки, архив, расчёт цены «под ключ»
- Проверки VIN: холд/списание ЮKassa, отправка готового отчёта клиенту на e-mail
- Настройки: курсы, логистика, комиссия, ЮKassa (в т. ч. чеки 54-ФЗ), контакты, реквизиты

## Установка
1. Скачайте `dist/china-car-importer.zip` и установите в WordPress («Плагины → Добавить новый → Загрузить плагин»).
2. Откройте «Авто из Китая → Обзор» и нажмите «Настроить автоматически»: создадутся главная, каталог, проверка VIN и политика.
3. Заполните «Настройки»: курсы, контакты, реквизиты, ключи ЮKassa (и пропишите адрес вебхука из настроек в кабинете ЮKassa).
4. Добавьте автомобили в разделе «Автомобили».

Требования: WordPress 6.0+, PHP 7.4+, красивые постоянные ссылки.

## Структура
```
china-car-importer/
├─ china-car-importer.php   точка входа, таблицы БД
├─ site-frontend.php        «холст» без темы, шапка/подвал, SEO, карточки, AJAX-калькулятор
├─ landing-page.php         главная + обработка заявки на подбор
├─ public-catalog.php       каталог + заявка на конкретный лот
├─ vin-check-page.php       проверка VIN, оплата, вебхук ЮKassa
├─ legal-page.php           шаблон политики конфиденциальности
├─ admin-panel.php          меню и «Обзор»
├─ cars-admin.php · leads-page.php · vin-requests-page.php · settings-page.php
├─ calculator-logic.php     расчёт цены «под ключ»
├─ yookassa-handler.php · email-notifications.php · importer-logic.php
└─ assets/ (css, js, media, demo)
```

## Важно
- Формулы пошлин и утильсбора **нужно сверить** с актуальными правилами таможни и с брокером до запуска.
- Сайт сам **не получает** отчёты Chaboshi: менеджер загружает готовый отчёт в админке, и он уходит клиенту письмом. Автоматизация возможна через API поставщика данных.
- Шаблон политики конфиденциальности требует проверки юристом.
